# 大疆视频转换工具

把大疆无人机 / 运动相机拍的视频，转成**所有浏览器都能直接播放**的格式，然后上传到 htyz.space。

---

## 为什么需要这个工具？

大疆默认录制的视频格式，浏览器**播不了**：

| 项目 | 大疆默认 | 浏览器需要 | 结果 |
|---|---|---|---|
| 视频编码 | **H.265 / HEVC** | H.264 (AVC) | ❌ Chrome、Firefox 完全不支持 |
| 位深 | **10-bit**（HLG / D-Log） | 8-bit | ❌ 硬件解码器普遍不支持 |
| 容器 | MOV | MP4 | ⚠️ 部分浏览器不支持 |
| 色彩 | HLG / D-Log | bt709 | ❌ 即使能播也严重偏色 |

所以直接上传后，页面上会显示**「视频格式错误」**——这不是网站的问题，是浏览器确实解不开大疆的编码。

**这个工具在你自己电脑上转**（用你的显卡硬件加速，几十秒搞定），比在服务器上转快几百倍。网站服务器只有 1 核 CPU，实测转一个 5 秒的 4K 视频要 5 分钟以上，而且期间整站会打不开。

---

## 怎么用

### 第一次准备（只需一次）

1. 确认电脑装了 **Node.js**（[下载地址](https://nodejs.org/)，选 LTS 版）
2. 双击 **`一键转换.command`**（macOS）或 **`一键转换.bat`**（Windows）
   - 首次会自动下载转换引擎（约 70MB，国内网络可用）

> macOS 如果提示「无法打开，因为无法验证开发者」：
> **右键点它 → 选「打开」→ 再点「打开」** 即可。

### 日常使用（三种方式任选）

**方式一：拖拽（最方便）**
把视频文件直接拖到 `一键转换.command` / `一键转换.bat` 上。

**方式二：放进文件夹**
把视频放进 `input/` 文件夹，然后双击入口文件。

**方式三：命令行**
```bash
node convert.mjs 我的视频.MP4
node convert.mjs a.MP4 b.MP4 c.MP4
```

### 转换完成后

转换好的文件在 **`output/`** 文件夹，名字带 **`-网页版`** 后缀。
**把这些文件上传到网站即可。** 原视频不会被修改或删除。

## 转换后的规格

| 项目 | 值 | 说明 |
|---|---|---|
| 编码 | H.264 High @ Level 4.1 | 兼容性最好的档位 |
| 分辨率 | 1080p | 已是 1080p 或更低则**不放大** |
| 位深 / 色彩 | 8-bit / bt709 | 修正大疆 HLG、D-Log 的偏色 |
| 音频 | AAC 128k 立体声 | 5.1 声道自动降为立体声 |
| 快速起播 | moov 前置 | 边下边播，不用等整个文件 |
| 元数据 | **已清除** | 见下方隐私说明 |

实测：4.6MB 的 4K 素材 → 0.8MB，减少约 83%。

---

## 隐私说明（重要）

大疆视频默认会写入以下信息，**上传到公开社区会泄露你的位置**：

- GPS 坐标
- 飞行轨迹
- 设备序列号
- 遥控器信息

本工具**默认清除全部元数据**。如果你确实需要保留（例如自己要存档），加 `--keep-meta`：

```bash
node convert.mjs --keep-meta 我的视频.MP4
```

---

## 可选参数

| 参数 | 作用 |
|---|---|
| `--4k` | 保留 4K 分辨率（默认降到 1080p）。文件会大很多，弱网观看会卡 |
| `--keep-meta` | 保留 GPS 等元数据（默认清除） |
| `--dry-run` | 只显示将要执行的操作，不实际转换 |
| `--help` | 显示帮助 |

## 常见问题

**Q：转换很慢？**
4K 素材通常 30 秒 ~ 3 分钟，取决于电脑。如果特别慢，可能是没用上硬件加速，可以试试加 `--4k` 反而更慢——建议保持默认的 1080p。

**Q：提示「没有检测到 Node.js」？**
去 [nodejs.org](https://nodejs.org/) 下载 LTS 版安装，然后重新双击。

**Q：提示「引擎准备失败」？**
检查网络。工具已配置国内镜像，若仍失败可手动执行：
```bash
npm install --registry=https://registry.npmmirror.com
```

**Q：转换失败怎么办？**
工具会打印 ffmpeg 的具体报错。常见原因：源文件损坏、磁盘空间不足、视频带加密保护。

**Q：能不能转其他相机的视频？**
可以。HEVC、MOV、MKV、AVI 都能转。iPhone 的 HEVC 视频同样适用。

**Q：转换后画质会变差吗？**
会有轻微损失（CRF 23 是画质与体积的平衡点），但 1080p 下肉眼基本无感。关键是**从"完全播不了"变成"能播"**。

## 技术说明

```bash
# 工具实际执行的命令（等价）
ffmpeg -i 输入.MOV \
  -vf "scale='if(gt(iw,1920),1920,iw)':-2:flags=lanczos,format=yuv420p" \
  -c:v libx264 -profile:v high -level 4.1 -preset medium -crf 23 \
  -pix_fmt yuv420p \
  -color_primaries bt709 -color_trc bt709 -colorspace bt709 \
  -c:a aac -b:a 128k -ac 2 \
  -movflags +faststart \
  -map_metadata -1 \
  输出-网页版.mp4
```

转换引擎通过 `@ffmpeg-installer` 获取，**不需要你手动安装 ffmpeg**。

> 注：该包提供的 ffmpeg 为 2018 年版本（4.1），编码 H.264 完全够用。
> 若你本机已有更新的 ffmpeg，工具会优先使用系统版本。
